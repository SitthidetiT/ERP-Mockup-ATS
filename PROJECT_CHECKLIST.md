# Project checklist

| Area | Delivery |
|---|---|
| Foundation | Next.js strict TypeScript app, responsive shell, local persistence |
| Dashboard | KPI cards, workload, activity, action queue |
| CRM | Searchable customers and persisted add-customer form |
| Quotation | List, builder, inline items, auto totals, preview, acceptance |
| Jobs | Connected Kanban workflow and activity recording |
| Operations | PARTIAL — routes resolve and generic workflow actions persist; domain records remain unimplemented |
| Costing | PARTIAL — restricted presentation view, but no actual-cost model or permission enforcement |
| HR / Administration | PARTIAL — navigation, role switcher and notification state; no HR/audit domain entities |
| Demo | Seed data, guide and reset action |
| QA | `npm run typecheck` and `npm run build` passed after audit remediation |
